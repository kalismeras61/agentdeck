# Translating AgentDeck's interface

AgentDeck's own text (menus, buttons, labels, notices, errors written by the frontend) is translated. Agent output, code, commands, file names and anything the user typed are never translated.

## The API (`src/lib/i18n.ts`)

```ts
import { t, tn } from "../lib/i18n";

t("New session")                                   // plain text
t("Moved to {name}", { name: project.name })       // placeholders in braces
tn(files.length, "{n} file", "{n} files")          // plurals: English one/other; {n} is the count
tn(n, "{n} agent is working", "{n} agents are working", { who })   // extra placeholders too
```

The English text is the key. With no translation, the English shows.

## Rules for wrapping strings

1. **Wrap what a person reads**: JSX text, and these props/fields when they hold prose: `title`, `aria-label`, `placeholder`, `label`, `hint`, `lede`, `description`, `note`, notice/error `title`/`message`/`text` built in the normalizers, `alt`, `caption` (only when it's prose, not a file name), option labels, tooltips, toasts, confirm text.
2. **Template literals become placeholders.** `` `Moved to ${to}` `` → `t("Moved to {name}", { name: to })`. Keep whole sentences in one key; never build a sentence by concatenating translated fragments (word order differs between languages).
3. **Plurals** use `tn`. Replace `n === 1 ? "file" : "files"` patterns.
4. **Don't translate**: product and agent names (AgentDeck, Claude Code, Codex, Gemini CLI, Grok Build, Kimi Code, Antigravity), model ids, commands and flags (`/compact`, `--resume`, `git push`), file paths, keyboard keys (⌘K, Esc, ↵), `APPROVED`/`DONE` protocol words, JSON keys, CSS classes, event `kind`/`type` values, ids, regexes, console logs, anything compared in code or stored in the database (for example the session title `"New session"` is compared by the Rust backend: keep that literal as is where it is stored or compared; you may wrap it only where it's displayed).
5. **Only call `t()` while rendering or inside functions that run at render/normalize time.** Never at module top level (`const X = t("…")` at import time would freeze English). For module-level tables of labels, keep the English in the table and call `t(label)` where it's shown, and mark the table with `/* i18n */` right before its `[` or `{` (`const LEVELS = /* i18n */ [ … ]`) so the extractor lists its strings.
6. Keep markup intact: for a sentence with an inline `<code>` or link, split into placeholders only if the parts are full phrases; otherwise wrap the text segments around the element separately (`{t("Run")} <code>kimi login</code> {t("in a terminal.")}` is acceptable when unavoidable, but prefer whole sentences with `{placeholders}` and render the code text inside).
7. Don't change behavior, layout or class names. Don't rename keys in tests; tests expect English and `t()` returns English when there's no translation.

## Checks

`npx tsc -b` and `npx vitest run` must pass. `node scripts/i18n-extract.mjs` writes every key to `src/locales/en.json`.

## Right-to-left

Arabic switches `<html dir="rtl">`. Layout uses logical Tailwind utilities (`ms-`/`me-`/`ps-`/`pe-`/`start-`/`end-`/`text-start`/`border-s`/`rounded-s`), so it mirrors on its own. Code, diffs, terminals, paths and commands stay left-to-right (`dir="ltr"`). Directional icons (chevrons, arrows) flip with `rtl:-scale-x-100`.
