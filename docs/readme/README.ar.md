# AgentDeck

**مساحة عمل واحدة على Mac لكل وكلاء البرمجة بالذكاء الاصطناعي التي تستخدمها أصلًا.**

شغّل Claude Code وCodex وGemini CLI وKimi Code ونماذجك الخاصة جنبًا إلى جنب. اقرأ عملها كمخرجات نظيفة ومنظَّمة، وراجع كل الفروقات، وأجب عن أسئلتها وطلبات الموافقة في مكان واحد، ودعها تخطّط وتبني وتراجع أعمال بعضها بعضًا.

أدوات CLI الخاصة بك. حساباتك. دون الحاجة إلى مفاتيح API.

## لماذا AgentDeck

وكلاء البرمجة رائعون في الطرفية، إلى أن تشغّل ثلاثة منهم عبر خمسة مشاريع. تضيع طلبات الموافقة مع التمرير، وتُدفن الفروقات في السجلات، ولكي يتحقق وكيل من عمل وكيل آخر لا بد من النسخ واللصق.

يُبقي AgentDeck الوكلاء كما هي تمامًا، ويمنحها مساحة عمل لائقة:

- **يشغّل أدوات CLI الحقيقية.** تبدأ `claude` و`codex` و`gemini` من تثبيتك أنت، بنفس PATH والإعدادات وتسجيل الدخول كما في Terminal. ما يعمل في طرفيتك يعمل هنا.
- **لا يلمس بيانات اعتمادك أبدًا.** يسجّل كل وكيل الدخول عبر آليته الخاصة. لا يقرأ AgentDeck الرموز المميزة (tokens) ولا يخزّنها ولا يرسلها؛ أما مفاتيح API التي تضيفها لنماذجك الخاصة فتبقى في سلسلة مفاتيح macOS.
- **كل شيء يبقى على جهاز Mac الخاص بك.** تُحفظ الجلسات في قاعدة بيانات SQLite محلية. لا حساب، ولا قياس عن بُعد، ولا خادم.

## ما الذي يمكنك فعله

### اعمل مع أي وكيل، في أي مشروع

كل مشروع هو مجلد، وكل جلسة هي وكيل واحد يعمل فيه. بدّل الوكيل قبل الرسالة الأولى، واختر من بين كل النماذج التي يتيحها كل وكيل، وبدّل النموذج في منتصف المحادثة. ابدأ محادثة دون مشروع، أو انقل الجلسات بين المشاريع، أو أعد تسميتها، أو استورد الجلسات التي حفظها Claude Code وCodex وGemini CLI مسبقًا على جهازك؛ فتواصل المحادثة نفسها.

اختر أيضًا مدى عمق تفكير الوكيل. يحصل Claude Code وCodex على إعداد **الجهد** بجانب النموذج (من منخفض إلى أقصى، مع المستويات التي يدعمها ذلك النموذج فقط). تعرض القائمة الجهد الذي يستخدمه الوكيل الآن، ويُطبَّق التغيير فورًا أثناء عمل Claude Code، ومن الإعدادات تحدّد الجهد الذي تبدأ به الجلسات الجديدة.

### راجع ما تغيّر، كما تراجع طلب سحب

يظهر كل ملف يلمسه الوكيل بعرض فروقات جنبًا إلى جنب أو موحَّد، ملفًا تلو الآخر، مع التنقل بلوحة المفاتيح وعلامات «معروض». لا يُودَع (commit) أو يُدفَع (push) أي شيء نيابةً عنك.

تظهر لقطات الشاشة والصور التي يلتقطها الوكيل أو يطّلع عليها (لقطة من المحاكي، صفحة معروضة، صورة يقرؤها) مباشرةً في المحادثة وفي تبويب «معاينة»؛ انقر على أيّ منها لعرضها بالحجم الكامل.

![مراجعة تغييرات وكيل جنبًا إلى جنب](../screenshots/readme/review.png)

### وافِق، أو ارفض، أو دعه يسأل

تظهر الأوامر والتعديلات التي تحتاج إلى موافقتك على شكل بطاقات توضّح ما الذي سيُشغَّل وأين، وما الذي سيتأثر به، ومدى خطورته. يتيح وضع التخطيط للوكيل أن يقرأ ويقترح قبل أن يغيّر أي شيء. وعندما يكون لدى الوكيل سؤال (AskUserQuestion في Claude Code، وrequest_user_input في Codex)، يظهر لك نموذج حقيقي: اختر خيارًا واحدًا أو عدة خيارات، أو اكتب إجابتك بنفسك.

![وكيل يطرح سؤالين، أحدهما باختيار واحد والآخر باختيارات متعددة](../screenshots/readme/question.png)

### دع الوكلاء يعملون معًا

- **مسارات العمل: الخطة ← البناء ← المراجعة.** ضع أي وكيل في كل مرحلة، مثلًا: Claude Code يخطّط، وCodex يبني، وClaude Code يراجع. تُسلِّم كل مرحلة عملها فور انتهائها، وتعود ملاحظات المراجعة مباشرةً إلى الباني، ويتوقف المسار عندما يكتب المراجِع APPROVED. تُمنح الموافقة على الطلبات العادية نيابةً عن الوكلاء؛ أما الطلبات الخطرة (الحذف، والدفع، والنشر، وبيانات الاعتماد، وأي شيء خارج المشروع) فتبقى بانتظارك.
- **التسليم.** أرسل أي خطة أو رد إلى وكيل آخر بنقرة واحدة.
- **التتابع.** يتحاور وكيلان حتى يقول أحدهما DONE.

![مسار عمل خطة وبناء ومراجعة: بنى Codex، وراجع Claude Code ووافق](../screenshots/readme/workflow.png)

### بوتات تواصل العمل

البوت وكيلٌ دائم. امنحه اسمًا ودورًا وتعليمات ووكيلًا ونموذجًا (Claude Code أو Codex أو Gemini CLI أو Grok Build أو Kimi Code أو Antigravity أو نماذجك الخاصة)، ثم أسند إليه المهام. ينجزها في الخلفية بينما تنشغل أنت بشيء آخر.

- **مكانٌ خاص به.** لكل بوت مجلده الخاص (`~/AgentDeck/Bots/<name>`)، ويعمل فيه ما لم تحدّد المهمة مشروعًا. يمكنك توجيه أي مهمة إلى أي مشروع؛ فالبوت يحتفظ بمحادثة منفصلة لكل مكان، ولذلك يتذكّر ما فعله وأين.
- **قائمة انتظار للمهام.** أضف مهام بينما البوت مشغول؛ فهو ينفّذها واحدة تلو الأخرى. أوقفها مؤقتًا أو استأنفها أو ألغِها أو أعد محاولتها، وتحتفظ كل مهمة منتهية بتقرير البوت نتيجةً لها.
- **الذاكرة.** يحتفظ كل بوت بملف ذاكرة قصير في مجلده. يقرؤه في بداية كل مهمة ويدوّن فيه ما يستحق التذكّر: اصطلاحات العمل، والقرارات، وأماكن الأشياء، وما تفضّله. يمكنك قراءته وتحريره في صفحة البوت.
- **الجداول.** «أيام العمل الساعة 9:00: راجِع طلبات السحب التي دُمجت أمس»، «كل 6 ساعات: ابحث عن الاختبارات غير المستقرة». تنضم كل مرة تشغيل إلى قائمة الانتظار مثل أي مهمة.
- **بوت مدير.** يمكن للبوتات أن تسند أجزاءً من مهمة إلى بوتات أخرى وتنتظر نتائجها، عبر أدوات AgentDeck الخاصة (`list_bots`، `delegate_task`، `wait_for_tasks`). ويمكن لبوت قائد أن يوزّع العمل بين مراجِع ومختبِر وكاتب، ثم يجمع تقاريرهم معًا.
- **تنسيق عبر النماذج.** دع نموذجًا واحدًا يقود والبقية تنجز العمل: مدير على أقوى نماذجك يخطط ويراجع، وبُناة على Opus أو Sonnet أو Codex أو Gemini يكتبون الكود. امنح بوتًا عدة نماذج يختار منها، فيختار مديره لكل مهمة (نموذجًا أسرع للعمل البسيط وأقوى للعمل الصعب، ومقدار الجهد في التفكير). فعّل «كل مهمة في worktree خاص بها» فتعمل كل مهمة في فرع جديد، ليتمكن عدة بُناة من العمل على مستودع واحد في الوقت نفسه دون أن يعيق أحدهم الآخر. ويعرض كل بوت استهلاك مهامه (المهام، والرموز المميزة، والتكلفة بأسعار API) بجانب حدود خطة وكيله.
- **دون مراقبة، لا دون رقابة.** أثناء عمل البوت على مهمة، تُمنح الموافقة على الطلبات العادية نيابةً عنه داخل مجلده ومشروع المهمة. أما كل ما هو خطر (الحذف، والدفع، والنشر، وبيانات الاعتماد، وأي شيء في مكان آخر) وكل سؤال فيبقى بانتظارك، ويظهر البوت في الشريط الجانبي بعبارة «تحتاج إليك».
- **Telegram.** اربط بوت Telegram خاصًا بك (برمز مميز من @BotFather يُحفظ في سلسلة المفاتيح)، ثم اقرن محادثتك برمز. بعد ذلك اكتب مهمة من هاتفك وسيصلك رد البوت هناك؛ وابدأ باسم البوت («Reviewer: …») لتختار بوتًا بعينه. وعندما يحتاج إليك بوت، تصلك الخطوة الخطرة أو السؤال أو الخطة مع أزرار: السماح، والرفض، واختيار إجابة. يطلب AgentDeck الرسائل من Telegram بنفسه، فلا يُفتح أي شيء على جهاز Mac للإنترنت، ولا يُرد إلا على المحادثات التي قرنتها.

- **عمليات الربط.** يمكن للبوتات أن تتجاوز كتابة الكود. من الإعدادات ← عمليات الربط أضِف متصفحًا (Playwright)، وGitHub، وNotion، وتطبيقات التقويم والتذكيرات والبريد والملاحظات على جهاز Mac (عبر هذه التطبيقات والحسابات الموجودة فيها مسبقًا)، أو أي خادم MCP عبر أمر أو عنوان، كلٌّ منها بحسابك الخاص؛ وتبقى الرموز المميزة في سلسلة المفاتيح. ثم اختر لكل بوت ما يُسمح له باستخدامه. أثناء عمل البوت على مهمة، يُسمح بما تقرؤه عملية الربط؛ أما ما تغيّره (دمج طلب سحب، أو إضافة حدث، أو فتح مسودة بريد) فيبقى بانتظارك، إلا إذا سمحت لعملية الربط تلك بأن تتصرف من تلقاء نفسها. ولا يرسل أي بوت بريدًا أبدًا.
- **المشغّلات.** إلى جانب الجداول وTelegram، يتلقى البوت عملًا عندما تتغير صفحة ويب (سعر، أو إعلان)، أو تصل ملفات جديدة إلى مجلد، أو تحصل مشكلة (issue) أو طلب سحب على التسمية `agentdeck` في مستودعك، أو يستدعي سكربت على جهاز Mac الخطاف (hook) الخاص به (`curl -X POST http://127.0.0.1:47810/hooks/…`). ويمكن للبوتات أيضًا أن تُبلغك بشيء فورًا عبر `notify_me`، على Telegram وفي صورة إشعار.
- **بوتات جاهزة.** ابدأ من باحث، أو مساعد صندوق الوارد، أو مخطِّط اليوم، أو كاتب لوسائل التواصل الاجتماعي، أو مراقب، أو مطوّر، وغيّر ما تشاء.

![بوت ينجز المهام في قائمة انتظاره، وجداوله وذاكرته على بُعد علامة تبويب واحدة](../screenshots/readme/bots.png)

### وغير ذلك

- **إعداد الوكيل.** حرّر `CLAUDE.md` و`AGENTS.md` و`GEMINI.md` والمهارات والأوامر والوكلاء الفرعيين، على المستوى العام ولكل مشروع، في شجرة واحدة.
- **طرفية ذكية.** صدفتك (shell) الخاصة في مجلد المشروع. اسأل أي وكيل عن النص المحدد أو آخر 80 سطرًا، مع زر «اشرح هذا الخطأ» بنقرة واحدة.
- **أرفق أي شيء.** أفلت ملفات أو مجلدات، أو الصق لقطة شاشة، أو اختر ملفات. تصل الصور إلى الوكيل كصور.
- **نماذجك.** DeepSeek وKimi وGLM (Z.ai) وOllama وLM Studio وOpenRouter أو أي نقطة نهاية متوافقة مع OpenAI أو Anthropic، مع الموافقات ووضع التخطيط ومسارات العمل نفسها.
- **حدود الخطة في لمحة.** تحت مربع الرسالة، تعرض جلسات Claude Code وCodex مقدار ما استهلكته من حد الساعات الخمس والحد الأسبوعي، وموعد إعادة ضبطهما.
- **سجّل الدخول حيث يتعثّر.** عندما يحتاج وكيل إلى تسجيل الدخول، يشغّل زرٌّ آليةَ تسجيل الدخول الخاصة به في طرفية مدمجة ثم يعيد إرسال رسالتك.
- **يحدّث نفسه.** الإصدارات الجديدة موقَّعة وموثَّقة لدى Apple (notarized)، ويُتحقَّق من كل تحديث مقابل مفتاح مدمج في التطبيق قبل تثبيته.

### بلغتك

الواجهة كاملةً متاحة بـ **English، Türkçe، Deutsch، Русский، Español، Français، Português، 简体中文، 日本語، 한국어 والعربية**، مع تخطيط من اليمين إلى اليسار للعربية. يتبع AgentDeck لغة جهاز Mac، أو يمكنك اختيار لغة من الإعدادات ← المظهر. لا تُترجَم ردود الوكلاء ولا الشيفرة ولا الأوامر ولا أسماء الملفات أبدًا، ويجيب الوكلاء بأي لغة تكتب لهم بها.

## خفيف على جهاز Mac

AgentDeck تطبيق Tauri أصلي: نواة Rust صغيرة وWebKit الخاص بنظام macOS، دون محرك متصفح مضمَّن.

| | مقاس على جهاز Mac (بناء الإصدار، مراقب النشاط) |
|---|---|
| التنزيل | صورة قرص بحجم 22 MB (Apple Silicon + Intel في تطبيق واحد) |
| بعد التثبيت | 50 MB |
| الذاكرة، AgentDeck نفسه | ~31 MB للتطبيق + ~207 MB للواجهة + ~18 MB لمساعدات النظام ≈ **256 MB** |
| المعالج في وضع الخمول | **0.1 %**، دون أي استيقاظ أثناء الخمول |
| بدء التشغيل | تحمّل الواجهة حزمة رئيسية بحجم 446 KB؛ وتُحمَّل المراجعة والطرفية والمعرض والإعدادات عند فتحها |

تعمل الوكلاء كعمليات مستقلة وتستخدم ذاكرتها الخاصة، نحو 140–210 MB لكل منها أثناء العمل (مقاسة على Linux: Claude Code ~188 MB، وCodex ~159 MB). وللإبقاء على ذلك تحت السيطرة، يُغلَق الوكيل الذي يبقى خاملًا 10 دقائق (وتستمر محادثته عندما تكتب مجددًا)، ولا يبقى أكثر من 6 وكلاء مفتوحين في آن واحد، وتُحمَّل السجلات الطويلة 80 دورة في كل مرة.

## الوكلاء المدعومون

| الوكيل | كيف يتواصل معه AgentDeck | تسجيل الدخول |
|---|---|---|
| **Claude Code** | `claude` مع stream-json وأداة مطالبة الأذونات الخاصة به | Claude Pro أو Max أو Team أو Enterprise، أو Anthropic Console |
| **Codex** | `codex app-server`، JSON-RPC عبر stdio | خطة ChatGPT أو مفتاح OpenAI API |
| **Gemini CLI** | Agent Client Protocol | حساب Google Workspace أو Cloud، أو مفتاح Gemini API |
| **Grok Build** | Agent Client Protocol | حساب xAI أو مفتاح API |
| **Kimi Code** | `kimi acp`، Agent Client Protocol | خطة Kimi Code أو مفتاح Moonshot AI API |
| **Antigravity** *(تجريبي، معطَّل افتراضيًا)* | `agy` في الوضع headless مع stream-json | حساب Google؛ راجع الملاحظة في الإعدادات حول شروط Google |
| **نماذجك** | الوكيل المدمج في AgentDeck، أو داخل Claude Code لواجهات API المتوافقة مع Anthropic | مفتاح API في سلسلة المفاتيح |

ثبّت واحدًا على الأقل. تعرض شاشة التشغيل الأول الوكلاء الموجودة على جهازك، وتثبّت البقية أو تسجّل الدخول إليها بالأمر الرسمي لكل وكيل، في Terminal، حيث يمكنك أن ترى ما يفعله.

## التثبيت

1. نزّل أحدث ملف `AgentDeck-<version>.dmg` من [صفحة الإصدارات](https://github.com/kalismeras61/agentdeck/releases/latest).
2. اسحب AgentDeck إلى مجلد التطبيقات وافتحه. التطبيق موقَّع وموثَّق، لذا يُفتح بنقرة مزدوجة.
3. اتبع خطوات **البدء** لإعداد وكيل، ثم افتح مجلد مشروع.

macOS 12 أو أحدث، Apple Silicon أو Intel.

## كيف يعمل

```
┌──────────────────────── AgentDeck (Tauri app) ────────────────────────┐
│  React UI: conversation, diffs, approvals, questions, workflows       │
│                │  validated, provider-neutral events (Zod)            │
│  Rust core: sessions · SQLite · git · PTY · workflow engine           │
└──────┬──────────────┬──────────────┬──────────────┬───────────────────┘
       │ stream-json  │ JSON-RPC     │ ACP          │ OpenAI / Anthropic API
       ▼              ▼              ▼              ▼
   claude          codex app-server  gemini, grok,  your models
                                     kimi
   (your install, your sign-in, your folder)
```

- يعمل كل وكيل كعملية فرعية في مجلد الجلسة، ببيئة صدفة تسجيل الدخول الخاصة بك.
- تُخزَّن مخرجاته كما هي، ثم تُوحَّد في تدفق أحداث واحد (رسائل، واستدعاءات أدوات، وفروقات، وموافقات، وأسئلة، وخطط) ويُتحقَّق منها قبل عرض أي شيء. وكل ما يكون مشوَّه البنية يُعرض كخطأ واضح، ولا يُنفَّذ أبدًا.
- لا يجيب عن طلبات الموافقة إلا أنت، أو مسار عمل في حالة الطلبات العادية؛ ولا يُوافَق تلقائيًا على أي شيء خطر.
- لا تملك الواجهة الأمامية أي وصول إلى الصدفة: يمكنها فقط استدعاء أوامر AgentDeck الخاصة ذات النطاق الضيق.

## البناء من المصدر

المتطلبات: Node 22+ وRust 1.77+ وأدوات سطر الأوامر في Xcode.

```bash
npm install

npm run dev                 # web preview with labeled demo data, http://localhost:1420
npm run tauri dev           # desktop app

# Checks
npm run typecheck && npm run lint && npm test
(cd src-tauri && cargo fmt --check && cargo clippy && cargo test)

# End to end with the real CLIs against local stand-in APIs (no accounts needed)
python3 scripts/mock_anthropic.py 8787 & python3 scripts/mock_openai.py 8788 & python3 scripts/mock_gemini.py 8789 &
(cd src-tauri && AGENTDECK_IT=1 cargo test -- --ignored --test-threads=1)

npm run tauri build         # .app / .dmg
```

الإصدارات (موقَّعة، وموثَّقة، وعامة لكل المعالجات، وذاتية التحديث) موصوفة في [docs/RELEASING.md](../RELEASING.md)؛ وما تم بناؤه وكيف يُتحقَّق من كل جزء في [docs/STATUS.md](../STATUS.md)؛ وبروتوكولات الوكلاء في [docs/PROVIDERS.md](../PROVIDERS.md).

## المساهمة

نرحّب بالبلاغات (issues) وطلبات السحب (pull requests). شغّل الفحوصات أعلاه قبل فتح PR، واجعل نصوص الواجهة قصيرة وبسيطة.

**الترجمات.** أُعدّت ترجمات الواجهة بمساعدة الذكاء الاصطناعي وفُحصت بالاختبارات، لكن لم يراجعها متحدثون أصليون بعد، لذا نرحّب كثيرًا بالتصحيحات: حرّر `src/locales/<language>.json` وشغّل `node scripts/i18n-validate.mjs`. تمرّ نصوص الواجهة الجديدة عبر `t()`؛ راجع [docs/I18N.md](../I18N.md).

يُتاح AgentDeck بموجب رخصة AGPL، وبشكل منفصل بموجب ترخيص تجاري. وللحفاظ على هذه الإمكانية، يُطلب من المساهمين توقيع اتفاقية ترخيص المساهمين (CLA) عند أول طلب سحب لهم.
