**Custom models can run commands again.** With Claude Code's auto mode as your default (`"defaultMode": "auto"` in `~/.claude/settings.json`), sessions on a custom model profile (GLM, DeepSeek, Kimi, Ollama, …) had every command denied with "Auto mode is unavailable", because auto mode's safety check only runs on Anthropic's API. These sessions now start in Claude Code's normal mode: commands your permission rules already allow run straight away, and the rest follow your approval level in AgentDeck (set it to *auto* or *all* under Settings to stop being asked).
