**Bots of their own.** Every bot now has its own folder (`~/AgentDeck/Bots/<name>`) and works there unless a task names a project. Point any task at any project from the task box; the bot keeps a separate conversation for each place, so it remembers what it did where, and its memory file travels with it. Existing bots keep their project as their default and their memory moves to the new folder.

**Schedules.** Give a bot work that repeats: at set times on chosen weekdays ("weekdays at 9:00") or every few hours. Each run lands in the queue like any task; runs missed while your Mac was off aren't made up, and a run is skipped (and marked) if the previous one hasn't finished. "Run now" is one click away, and the sidebar shows the next run.

**A manager bot.** Bots can hand parts of a task to other bots and wait for their results, through AgentDeck's own tools (`list_bots`, `delegate_task`, `wait_for_tasks`). A lead bot can split work between a reviewer, a tester and a writer and put their reports together. Delegated tasks show who sent them, and the lead's task lists the work it handed out. Works with Claude Code, Codex, Gemini CLI, Grok Build and Kimi Code; cancelling a task cancels the work it handed out.

Also: plan limits under the message box (0.4.1), and unattended bots may now work in their own folder and the task's project; anything else still waits for you.

**Download `AgentDeck-0.5.0.dmg`**: one app for Apple Silicon and Intel, macOS 12 or later, signed and notarized. Installed copies update themselves.
