**`/remote-control` works in Claude Code sessions.** Type `/remote-control` (or `/rc`) in a Claude Code conversation and it continues in the Claude app or at claude.ai, through Claude Code's own Remote Control. AgentDeck hands the conversation over: it ends its own Claude Code process for that session and opens it in a terminal with `claude --resume … --remote-control`, which shows the QR code and the link. While it's there, AgentDeck doesn't start a second Claude Code on the same conversation. When you end it (End Remote Control, or `/exit` in its terminal), the conversation comes back to AgentDeck with the messages written meanwhile. Remote Control needs Claude Code signed in with a Claude plan (Pro, Max, Team or Enterprise); it isn't offered for custom model profiles or bots.

**Download `AgentDeck-0.5.1.dmg`**: one app for Apple Silicon and Intel, macOS 12 or later, signed and notarized. Installed copies update themselves.
