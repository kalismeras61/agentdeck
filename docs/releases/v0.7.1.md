**Approval levels for every agent.** Each agent now has a level for what it may do without asking, in the composer next to the model and in Settings → Providers:

- **Ask every time**: every edit and command waits for your OK (as before).
- **File edits**: edits inside the project go ahead; commands and everything else wait.
- **Auto**: edits and ordinary commands go ahead. Risky ones (deleting, pushing, deploying, secrets, sudo…) and anything outside the project wait for you, the same rule workflows use.
- **Everything**: nothing waits. Asks you to click twice before it turns on.

It's for Claude Code, Codex, Gemini CLI, Grok Build, Kimi Code and the Model API agent, and applies right away, including to requests already waiting. Questions and plans always wait for you, plan mode still refuses changes, and bots and workflows keep their own rules. Requests that went ahead this way say "Allowed by your approval setting" in the conversation. Antigravity keeps its own setting.
