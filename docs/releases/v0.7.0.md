**Orchestration across models.** Let your strongest model lead and others do the work.

- **A manager picks the model per task.** In a bot's settings, choose the other models a manager may run its tasks on. The manager then picks for each task: a quicker model for simple work, a stronger one for hard work, and how hard it thinks. Example: a manager on Fable or Opus that plans and checks, builders on Sonnet, Opus or Codex that write the code, a reviewer on another model.
- **Each task in its own worktree.** Turn it on for a bot and every task in a git project works in a fresh worktree on a new branch. Several builders can work on one repository at the same time without touching each other's files. The task's result names its branch; you (or a reviewer bot) merge it.
- **What bots use.** Each bot shows its finished tasks, tokens and cost at API prices for the last 24 hours, 7 and 30 days, next to its agent's plan limits, and each task its model, cost and branch. (Claude Code reports usage; other agents don't yet.)
