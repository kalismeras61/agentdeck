**Remove a project from the sidebar.** Hover a project and click the folder-minus icon next to its name. AgentDeck asks first, says how many sessions go with it, and stops agents running there. Nothing in the folder itself is touched, and you can add it again any time. Removing from Settings still works, and if removing fails it now says why instead of failing silently.

**Download `AgentDeck-0.7.2.dmg`**: one app for Apple Silicon and Intel, macOS 12 or later, signed and notarized. Installed copies update themselves.
