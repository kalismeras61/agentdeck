**Workflows show where they are.** In the sidebar, each session of a workflow has a mark for its stage: a green check when it's done, a dot for the one working now, an empty circle for what's next, and a warning where a workflow stopped.

**Antigravity in workflows.** With "Everything" allowed, Antigravity can now run commands in plan mode too, so a planner or reviewer can run tests and git diff instead of having them skipped (plan mode still keeps it from editing). A turn that ends without a reply no longer stops the workflow; it waits for the agent's next reply. Antigravity's file changes also show up when the project folder is reached through a symlink, and its example rule `command(<target>)` is no longer offered as something to allow.
